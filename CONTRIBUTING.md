# Contributing

Focused pull requests are welcome.

1. Open an issue before adding a rule or changing a rule's meaning.
2. Include examples that should and should not trigger.
3. Consider both English and Arabic behavior when a pattern is language-dependent.
4. Run `npm test` and `npm run check`.

Rules must identify a concrete ambiguity and suggest clarification. They must not infer the author's intended date, jurisdiction, or time zone.
